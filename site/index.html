Code teilen

Zum Teilen speichern wir dein Skript … auf unserem Server. Du bekommst zwei Links: einen, der die App direkt im Vollbild startet (er landet gleich in der Zwischenablage), und einen, der den Code öffnet. Jeder mit einem der Links kann den Code lesen.

Teilen ist auf diesem Server gerade nicht eingerichtet.

Als Programm herunterladen Beta

Dein Code aus … wird zu WebAssembly gebacken und in ein eigenständiges Programm verpackt – ganz ohne Server, direkt in deinem Browser. Beta: Noch lässt sich nicht jedes Programm als Programm backen.

Plattform

So startest du das Programm
  • Windows: Die .exe ist nicht signiert. Zeigt Windows SmartScreen „Der Computer wurde durch Windows geschützt“, klick auf Weitere Informationen → Trotzdem ausführen.
  • Linux: erst ausführbar machen: chmod +x programm && ./programm; braucht WebKitGTK 4.1 (Debian/Ubuntu: sudo apt install libwebkit2gtk-4.1-0).
  • Das Programm läuft in der Konsole/im Terminal. Interaktive Eingaben (Bestellannahme) tippst du dort ein; Strg+D (Windows: Strg+Z, Enter) beendet die Eingabe.

Pizza im Karton 📦

Dein Programm wurde zu WebAssembly kompiliert.

Nativ ausführen mit dem Host: pizza-host programm.pkarton
Zur EXE backen: pizzaofen exe programm.pkarton -o programm.exe
